# Microservices with Quarkus

Quarkus is "Supersonic Subatomic Java." Designed from the ground up for Kubernetes and Serverless environments, it boasts incredibly fast boot times and extremely low memory footprints.

## Live Coding

One of the best developer experience features is live coding. Just run `quarkus dev`.

```bash
./mvnw compile quarkus:dev
```

Any changes you make to Java files, application.properties, or HTML templates will automatically take effect instantly, with zero configuration.
